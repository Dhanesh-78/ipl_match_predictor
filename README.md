# IPL Analytics Dashboard

An interactive IPL Analytics project built using **Python, Tableau, Power BI, SQL, and Machine Learning** to analyze IPL matches, player performances, season trends, and predict match winners.

---

## 🌐 Live Streamlit App

Try the IPL Match Winner Predictor here:

[🏏 Open IPL Predictor App](https://dhanesh-iplmatch-predictor.streamlit.app/)

## Project Overview

This project focuses on:
- IPL Data Analysis
- Interactive Dashboards
- Data Visualization
- Machine Learning Prediction

The project uses:
- `matches.csv`
- `deliveries.csv`

datasets for complete IPL analysis.
